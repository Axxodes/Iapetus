# Iapetus (Game engine)

This game engine is open source so that improvements can find place faster and bugs can be readily fixed.
I want to keep this as the main page for my game engine.

Currently, only on windows. We're focusing on the game engine itself and only then we'll port it to other operating systems.

# What is Iapetus?

Iapetus is a C++ game engine with its main focus being optmisation: small file size, lightweight on cpu/gpu and relatively low RAM usage.

The renderer that we use is custom made and is called 'Hyperion' or in greek letters: Ὑπερίων, being the Greek titan of light.
It's meant to give the most we can for a lightweight engine.

# Why use Iapetus?

The engine is lightweight.
It allows for  lightweight games, so your game could run on even the eldest of computers.

# How to use Iapetus?

The .exe file is the application itself, you can run it with a command prompt or by double clicking it.
Games (and apps) created by this engine will also be an exe which can be run through Iapetus or like any other exe.

Build.bat should be ignored, it is to compile the engine with g++, if you adjust some code or assets, you will need to run it.

# Why the name Iapetus?

The name comes from Iapetus, the Greek Titan and father of Prometheus.
In this project, I like to think of you as Prometheus.
Just as Prometheus brought fire to humanity, I hope Iapetus gives developers the tools to create games that push the industry forward.
