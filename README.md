# Iapetus (Game engine)

This game engine is open source so that improvements can find place faster (I'm a solo dev) and bugs can be found quicker.
I want to keep this as the main page for my game engine.

# What is Iapetus?

Iapetus is a c++ game engine with its main focus being optmisation: small file size, lightweight on cpu/gpu and relatively low RAM usage.
(You can use brainfuck for easier compression but i personally think this is a little extreme lol)

# Why Iapetus?

The name comes from Iapetus, the Greek Titan and father of Prometheus.
In this project, I like to think of you as Prometheus.
Just as Prometheus brought fire to humanity, I hope Iapetus gives developers the tools to create games that push the industry forward.
